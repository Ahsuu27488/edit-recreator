# Third-party software

`edit-recreator` does not bundle any of these. Scripts download or import them from their official sources;
each keeps its own licence.

| Project | Used for | Licence |
|---|---|---|
| [Remotion](https://www.remotion.dev) | Rendering the edit in React | Remotion License (source-available; free for individuals and companies up to 3 people, company licence otherwise) |
| [rife-ncnn-vulkan](https://github.com/nihui/rife-ncnn-vulkan) (RIFE v4.6) | Slow-motion in-between frames | MIT |
| [Real-ESRGAN ncnn-vulkan](https://github.com/xinntao/Real-ESRGAN) | Upscaling | BSD-3-Clause |
| [BiRefNet](https://github.com/ZhengPeng7/BiRefNet) ([ONNX export](https://huggingface.co/onnx-community/BiRefNet-portrait-ONNX)) | Background removal | MIT |
| [rembg](https://github.com/danielgatis/rembg) | Alternative cut-out models | MIT |
| [GFPGAN](https://github.com/TencentARC/GFPGAN) | Optional face restoration | Apache-2.0 (check model-weight terms before commercial use) |
| [facexlib](https://github.com/xinntao/facexlib) | Face detection | MIT |
| [FFmpeg](https://ffmpeg.org) | Video I/O | LGPL/GPL (installed separately) |
| [OpenCV](https://opencv.org), [Pillow](https://python-pillow.org), NumPy, SciPy, ONNX Runtime | Image processing | Apache-2.0 / MIT-CMU / BSD |
