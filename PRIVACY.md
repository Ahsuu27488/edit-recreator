# Privacy policy: edit-recreator

edit-recreator is a Claude Code plugin made of a skill, Python scripts and Node scripts that run on your own computer.

- **No data collection.** The plugin collects, stores and sends no personal data, telemetry or analytics. Its author receives nothing.
- **Your media stays local.** Reference videos, photos and clips you work with are read and written only on your machine.
- **Downloads.** When you run `scripts/fetch_tools.py`, or a model loads for the first time, open-source tools and model weights are downloaded from their official sources (GitHub releases, Hugging Face). Those requests go straight to those sites under their own privacy policies; no data about you or your media is sent.
- **Claude.** Like any Claude Code skill, the instructions and the files you ask Claude to look at are processed by Claude under Anthropic's own terms and privacy policy.

Questions: open an issue at https://github.com/Ahsuu27488/edit-recreator/issues
